# My Work Day

Статический сайт для личного планирования задач и учёта времени. Сделан на React, Vite и TypeScript. Оформление вдохновлено маркерной доской: светлые панели в раме на фоне рабочего места. Сервер и учётная запись не нужны: задачи, записи времени и состояние таймера сохраняются в IndexedDB браузера.

## Возможности

- Задачи выбранного дня со статусами «Сделать», «В работе», «Готово», проектом, сроком, заметками и оценкой времени.
- Календарь с панелями новой задачи, задач выбранного дня и учёта времени.
- Компактные поля задач и времени в календаре: начало и конец записи задают длительность, а пустой конец запускает таймер для сегодняшнего дня.
- Отдельная «Статистика» с показателями за выбранный день и период.
- Отчёты за день, неделю, месяц и год; скачивание отчёта в Markdown.

## Локальный запуск

Нужен Node.js с поддержкой Vite 8.

```bash
npm install
npm run dev
```

Проверка и сборка:

```bash
npm run build
npm test
npm run preview
```

Готовый сайт находится в `dist/`. В `vite.config.ts` установлен `base: './'`, поэтому сборка работает в подпапке GitHub Pages.

## GitHub Pages

Если этот каталог является корнем отдельного репозитория GitHub, workflow `.github/workflows/deploy.yml` собирает и публикует сайт при push в `main`. В настройках репозитория выберите **Settings → Pages → Build and deployment → GitHub Actions**.

Данные остаются только в браузере и профиле, где они были созданы. Очистка данных сайта или смена браузера удалит доступ к ним; синхронизации между устройствами нет.
