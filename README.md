# My Work Day

Статический сайт для личного планирования задач и учёта времени. Сделан на React, Vite и TypeScript. Оформление вдохновлено маркерной доской: светлые панели в раме на фоне рабочего места. Сервер и учётная запись не нужны: задачи, записи времени и состояние таймера сохраняются в IndexedDB браузера.

Логотип и набор интерфейсных иконок находятся в `public/icons/`. Это отдельные SVG-изображения с едиными линиями и цветом; они используются в навигации, кнопках и как значок вкладки браузера.

## Возможности

- Несколько досок с редактируемыми названиями и карусельным переходом. Боковые стрелки переключают соседние доски, а `+` на краю создаёт новую. Удерживание Shift меняет действие: стрелка на краю переносит на противоположный конец, а `+` между досками вставляет промежуточную. Доску можно удалить внизу боковой панели после подтверждения.
- Задачи выбранного дня со статусами «Сделать», «В работе», «Готово», проектом, сроком, заметками и оценкой времени; добавление через `+` и редактирование прямо в строке.
- Календарь с общим переключателем даты, задачами дня и отдельной панелью задач «На любой день». Задачи можно переносить на выбранный день и обратно одной кнопкой.
- Кнопка с часами в форме добавления и редактирования задачи раскрывает начало и окончание работы. Заполненное окончание сохраняет длительность, а пустое запускает таймер для сегодняшнего дня.
- Отдельная «Статистика» с показателями за выбранный день, неделю, месяц или год.
- Отчёты за день, неделю, месяц и год с подходящим полем выбора периода; текст Markdown доступен для просмотра и копирования прямо на странице.

## Локальный запуск

Нужен Node.js с поддержкой Vite 8.

```bash
npm install
npm run dev
```

Проверка и сборка:

```bash
npm run build
npm test
npm run preview
```

Готовый сайт находится в `dist/`. В `vite.config.ts` установлен `base: './'`, поэтому сборка работает в подпапке GitHub Pages.

## Структура `src/`

- `app/` — карусель досок, переключение и создание досок.
- `boards/` — содержимое одной доски, боковая панель, сетка досок и навигация.
- `views/` — экраны задач и календаря, заголовок с выбором даты и учёт времени.
- `forms/` — формы добавления и редактирования задач.
- `reports/` — расчёт итогов периода и отображение статистики и отчёта.
- `data/` — типы данных и работа с IndexedDB.
- `lib/` — функции дат, таймера и планирования задач.
- `backgrounds/`, `assets/`, `ui/` — фон, изображения и общие элементы интерфейса.
- `styles/` — стили по областям интерфейса; порядок подключения задан в `main.tsx`, адаптивные правила подключаются последними.

## GitHub Pages

Если этот каталог является корнем отдельного репозитория GitHub, workflow `.github/workflows/deploy.yml` собирает и публикует сайт при push в `main`. В настройках репозитория выберите **Settings → Pages → Build and deployment → GitHub Actions**.

Данные остаются только в браузере и профиле, где они были созданы. Очистка данных сайта или смена браузера удалит доступ к ним; синхронизации между устройствами нет.

Существующие задачи и время остаются в исходной базе IndexedDB `todo-did` и становятся первой доской. Каждая новая доска получает отдельную базу; названия, порядок и выбранная доска хранятся в `todo-did-boards`.
