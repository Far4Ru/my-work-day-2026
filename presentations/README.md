# Скриншоты приложения

Добавьте в эту папку изображения экранов с такими именами:

- `all-boards.png` — экран «Все доски»;
- `tasks.png` — задачи на доске;
- `calendar.png` — календарь;
- `statistics.png` — статистика;
- `reports.png` — отчёты.

README проекта уже ссылается на эти файлы. Рекомендуемый формат — PNG в разрешении 1858×993 или близком к нему.
