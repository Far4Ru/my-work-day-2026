# Фоны рабочего стола

Двенадцать панорам используются по местному времени устройства, каждая в течение
двух часов. `desk-XX.jpg` сохранены как исходные кадры для соответствующего освещения;
`desk-12.jpg` — сжатая копия исходного `workspace-desk.png`.
Остальные кадры стола созданы встроенным imagegen как правки исходной фотографии.

Общий промпт: изменить только освещение и вид за окном для указанного времени
суток. Сохранить точное положение камеры, кадрирование 16:9, окно, стол,
растение слева, блокнот и ручку внизу слева, стакан с карандашами и наушники
справа. Центр стола оставить свободным под интерфейс. Фотореализм; без новых
или удалённых предметов, текста и элементов UI.

| `10` | Ясное позднее утро, нейтральный дневной свет |
| `12` | Исходный дневной кадр |

Для каждого двухчасового интервала есть `window-panorama-XX.png` размером 1122 × 1402 пикселя. Нижняя часть показывает стол, верхняя — фронтальный вид из окна, между ними — короткий участок смены перспективы. Весь фон перемещается одним изображением без внутренних стыков. При смене временного интервала следующий кадр предварительно загружается и плавно заменяет предыдущий.

`window-view-14.png` и `window-front-14.png` сохранены как исходные варианты разработки дневной панорамы; приложение их больше не загружает.
