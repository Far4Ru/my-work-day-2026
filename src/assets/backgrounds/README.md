# Фоны рабочего стола

Двенадцать кадров используются по местному времени устройства, каждый в течение
двух часов. `desk-12.jpg` — сжатая копия исходного `workspace-desk.png`.
Остальные кадры созданы встроенным imagegen как правки исходной фотографии.

Общий промпт: изменить только освещение и вид за окном для указанного времени
суток. Сохранить точное положение камеры, кадрирование 16:9, окно, стол,
растение слева, блокнот и ручку внизу слева, стакан с карандашами и наушники
справа. Центр стола оставить свободным под интерфейс. Фотореализм; без новых
или удалённых предметов, текста и элементов UI.

`window-view-14.png` — пробный фон сетки досок для дневного кадра `desk-14.jpg`: взгляд выше в то же окно, без повторения стола и нижней рамы. При открытии сетки основной фон уходит вниз, а этот приходит сверху; при возврате движение обратное. Пока он используется как единственный вариант вида из окна.
